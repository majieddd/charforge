CharForge Playground

Two characters, each generated from a text prompt on a laptop — geometry, skeleton and skinning all local. Pick one from the roster, bottom right, or see what it takes to make your own. Geometry comes from stochastic multi-view conditioning, retopologised to a watertight quad mesh with albedo and normal baked from the high-resolution surface, then Mixamo capture retargeted onto a T-posed rig and skinned throughout.

Deformation uses dual quaternion skinning: glTF carries one weight set and viewers apply it linearly, which hollows out the inside of every bent joint. Blending the rotations as rotations instead takes jacket faces collapsed below half their rest area from 8.8% to 6.1% over the walk. Toggle it to see the difference.

CharForge is a local pipeline, not a hosted service — there is no “generate” button to press here.

Everything that made the characters in this playground runs on one Apple Silicon laptop: generation, segmentation, retopology, rigging, skinning and animation. Nothing is sent anywhere. That is the point of it, and it is also why the generator cannot live on this page — it needs Blender, the TRELLIS.2 weights and about 20 GB on disk.

  1. Clone the repository and install the host dependencies
  2. Run tools/check_env.py — it reports anything missing across all three environments before a long run starts
  3. Give charforge.py make a prompt or an image, and a name
git clone https://github.com/majieddd/charforge
cd charforge
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python tools/check_env.py

.venv/bin/python charforge.py make --prompt "a knight in weathered plate armour" --name knight
.venv/bin/python charforge.py make --image my_concept.png --name hero --height 1.85

About twenty minutes later out/<name>/ holds a character that follows engine convention: real height in metres, origin between the feet, a Mixamo-named skeleton so any Mixamo animation applies to it, glTF and FBX, and the texture maps each engine reads — plus a manifest recording clip timing and ground speeds.
